## How each task is kept

- Folder name: `YYYY-MM-DD-product-short-name` (product is `riskmandate`, `newsroom` or `sgit`), so tasks sort by date and show which product they cover. Folders made before this rule keep their names, so existing links still work.
- Each folder has its own `README.md` (and a web page where there is one) with what I tested, what happened, and what I suggest.
- Related tasks link to each other from their own README.
- New tasks follow [`TEMPLATE.md`](TEMPLATE.md).
